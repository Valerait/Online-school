## 🔧 Как протестировать

### Шаг 1: Получить Session ID
1. Зайти в админ-панель: https://online-school-online-school-nextjs.vercel.app/login
2. Войти как админ: `newadmin@example.com` / `admin123`
3. Открыть DevTools (F12) → Application → Local Storage
4. Найти ключ с session ID и скопировать значение

### Шаг 2: Открыть тестовую страницу
1. Открыть: https://online-school-online-school-nextjs.vercel.app/test-admin-functions.html
2. Вставить Session ID в поле и нажать "Сохранить"
3. Тестировать все функции по очереди

### Шаг 3: Тестирование функций

#### 📊 Статистика
- ✅ `GET /admin?action=stats` - общая статистика системы

#### 👥 Пользователи  
- ✅ `GET /admin?action=users` - список всех пользователей
- ✅ `POST /admin?action=create-user` - создание пользователя
- ✅ `POST /admin?action=update-user-role` - изменение роли
- ✅ `POST /admin?action=delete-user` - удаление пользователя

#### 👨‍🏫 Преподаватели
- ✅ `GET /admin?action=teachers` - список преподавателей
- ✅ `POST /admin?action=create_teacher` - создание преподавателя
- ✅ `POST /admin?action=update_teacher_status` - изменение статуса

#### 📚 Уроки и заявки
- ✅ `GET /admin?action=lessons` - список уроков
- ✅ `GET /admin?action=bookings` - список заявок
- ✅ `POST /admin?action=update-lesson-status` - изменение статуса урока
- ✅ `POST /admin?action=update-booking-status` - изменение статуса заявки
- ✅ `POST /admin?action=delete-lesson` - удаление урока

#### 💰 Платежи
- ✅ `GET /admin?action=payments` - список платежей
- ✅ `POST /admin?action=create-payment` - создание платежа
- ✅ `POST /admin?action=update-payment-status` - изменение статуса

#### 📈 Отчеты
- ✅ `GET /admin?action=reports` - получение отчета
- ✅ `GET /admin?action=export-report` - экспорт отчета
