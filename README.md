# 🎓 Онлайн-школа

Современная платформа для онлайн-обучения с видеозвонками, системой бронирования уроков и административной панелью.

## 🚀 Возможности

### 👨‍🎓 Для студентов
- Регистрация и авторизация по номеру телефона
- Бронирование пробных и платных уроков
- Личный кабинет с историей уроков
- Видеозвонки через Jitsi Meet
- Система оплаты уроков

### 👨‍🏫 Для преподавателей
- Отдельная авторизация для преподавателей
- Личный кабинет с управлением расписанием
- Принятие/отклонение заявок на уроки
- Проведение видеоуроков
- Добавление комментариев и домашних заданий

### 👨‍💼 Для администраторов
- Полная админ-панель с контролем системы
- Управление пользователями и преподавателями
- Назначение преподавателей на уроки
- Контроль уроков и платежей
- Отчеты и аналитика
- Статистика системы

## 🛠 Технологии

### Frontend
- **Next.js 16** - React фреймворк с App Router
- **TypeScript** - строгая типизация
- **Tailwind CSS** - современная стилизация
- **Jitsi Meet React SDK** - видеозвонки
- **React 19** - последняя версия React

### Backend
- **Supabase** - Backend-as-a-Service
- **Edge Functions** - серверная логика на Deno
- **PostgreSQL** - реляционная база данных
- **RLS (Row Level Security)** - безопасность на уровне строк

### Деплой и инфраструктура
- **Vercel** - деплой фронтенда
- **Supabase Cloud** - хостинг бэкенда
- **Git** - версионирование кода

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/Valerait/Online-school.git
cd Online-school
```

### 2. Установка зависимостей
```bash
# Next.js приложение
cd online-school-nextjs
npm install
cd ..
```

### 3. Настройка окружения
```bash
# Скопируйте файл окружения в папку Next.js
cd online-school-nextjs
cp .env.example .env.local

# Настройте переменные в .env.local:
# NEXT_PUBLIC_SUPABASE_URL=https://obzatycdwtdmhgqotbgs.supabase.co
# NEXT_PUBLIC_SUPABASE_ANON_KEY=your_anon_key
```

### 4. Запуск приложения
```bash
# Запустите Next.js в режиме разработки
cd online-school-nextjs
npm run dev
```

Приложение будет доступно по адресу: http://localhost:3000

## 📊 База данных

### Основные таблицы
- `users` - пользователи системы (студенты)
- `teachers_new` - данные преподавателей
- `lessons` - проведенные уроки
- `bookings` - заявки на уроки
- `payments` - платежи за уроки
- `sessions` - пользовательские сессии
- `lesson_notes` - комментарии к урокам

### Роли пользователей
- `student` - студент (по умолчанию)
- `teacher` - преподаватель (отдельная таблица)
- `admin` - администратор системы

### Ключевые функции
- **Автоназначение преподавателей** - система автоматически находит подходящих преподавателей по предмету
- **Управление статусами** - отслеживание статусов заявок, уроков и платежей
- **Безопасность RLS** - защита данных на уровне строк

## 🔐 Безопасность

- **RLS (Row Level Security)** - защита данных на уровне строк
- **JWT токены** - безопасная авторизация через Supabase
- **Хеширование паролей** - защита паролей пользователей
- **Проверка ролей** - контроль доступа к функциям
- **CORS настройки** - защита от межсайтовых запросов
- **Валидация данных** - проверка входящих данных на сервере
